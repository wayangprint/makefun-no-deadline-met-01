One funny single-line excuse for a missed deadline — the whole morning went into rehearsing the apology for missing it.

> "I missed the deadline because I spent all morning rehearsing the apology for missing the deadline."

## Competition

Entry for [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) — one line, under 200 characters, judged head to head by an AI judge in three blind rounds. $2 pool over 5 paid places.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (1–200 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
